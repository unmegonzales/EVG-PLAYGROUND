# Zia Two — VIP Beverage Menu

Print-ready **8.5″ × 11″** vertical redesign of the Zia Two beverage board, elevated to a premium VIP hospitality look while applying every markup from the attached proof.

## Open / print

1. Open `zia-two-vip-menu/index.html` in Chrome.
2. Use **Print / Save PDF** (or the on-page button).
3. Paper size: **Letter**. Scale: **100%**. Enable **Background graphics**.

## Markup applied

| Change | Result |
| --- | --- |
| Domestic Beer 16 oz `12.00` → handwritten `12.50` | **12.50** |
| Beer Alternatives `14.00` → handwritten `16.00` | **16.00** |
| Premium Wine `* Double $28` | Kept **15.00**, added double-pour note **28.00** |
| Top Shelf Cocktails `17.00` struck / `$18.00` written | **18.00** |
| Souvenir Cup struck through | **Removed** |
| `Pour = 1.25` | Footer: **Standard pour 1.25 oz** |
| 16 oz Soda complimentary | Kept |

Unchanged from the printed proof: Premium Beer 16/24, House Wine, Premium Cocktails, Bottled Water.
