# Zia Two — VIP Beverage Menu

Print-ready **8.5″ × 11″** vertical redesign of the Zia Two beverage board, elevated to a premium VIP hospitality look while applying every markup from the attached proof.

## Open / print

1. Open `index.html` in Chrome.
2. Use **Print / Save PDF** (or the on-page button).
3. Paper size: **Letter**. Scale: **100%**. Enable **Background graphics**.

Or use the shipped proof: `exports/Zia-Two-VIP-Beverage-Menu.pdf`.

## Adobe edits (self-managed)

**Yes — use the Illustrator SVG, not only the PDF.**

| Deliverable | Use |
| --- | --- |
| `exports/Zia-Two-VIP-Beverage-Menu-editable.svg` | **Open in Adobe Illustrator** → live text → **Save As `.ai`** for ongoing edits |
| `exports/Zia-Two-VIP-Beverage-Menu.pdf` | Print / email / proof (not the best edit master) |

See `scripts/README-adobe.md` for the full Adobe workflow.

## Current type & pricing

- Slightly larger type hierarchy than the first VIP draft
- Whole-dollar prices omit `.00` (example: `14`, `16`, `18`)
- Non-whole amounts keep decimals (`12.50`)

## Markup applied

| Change | Result |
| --- | --- |
| Domestic Beer 16 oz `12.00` → handwritten `12.50` | **12.50** |
| Beer Alternatives `14.00` → handwritten `16.00` | **16** |
| Premium Wine `* Double $28` | **15** + double-pour note **28** |
| Top Shelf Cocktails `17.00` struck / `$18.00` written | **18** |
| Souvenir Cup struck through | **Removed** |
| `Pour = 1.25` | Footer: **Standard pour 1.25 oz** |
| 16 oz Soda complimentary | Kept |
