Print Package Guide

UNM Lobos · 25/26 Football Concessions · Fireup dimensions · Designer change sheet applied

Important for the printer: Browser “Save as PDF” from this HTML menu is an RGB proof / layout reference, not a final press-ready CMYK package. Use the table below for exact trim sizes, then rebuild or convert in your production workflow (Illustrator / InDesign / RIP) to PDF/X · CMYK before output.

1. How to export from the HTML menu

  1. Open menu-standalone.html (or the live app).
  2. Go to Single Board.
  3. Choose the location in the dropdown (size is listed).
  4. Click Print / PDF.
  5. In the print dialog: Destination = Save as PDF, enable Background graphics, margins = None / default from CSS, and confirm the paper size matches the Fireup size when Chrome offers a custom size.
  6. Name files clearly, e.g. 05_RedRally_Interior_96x36_RGB-proof.pdf.
Best practice: Export one board at a time from Single Board so the dynamic @page size matches that location. Full Deck print is for internal review only (shared 96×36 proof size).

3. Color: RGB vs CMYK

  • HTML / browser PDF = RGB. UNM brand hex values used in file: Cherry #BA0C2F, Silver #A7A8AA, Metal #4A4F55, Turquoise #00A8B5, Light #F4F4F6.
  • Final print files should be CMYK (or as specified by Fireup / your RIP), converted with a agreed profile (e.g. SWOP / GRACoL / printer-supplied ICC).
  • Expect slight shifts on Cherry Red and Turquoise after conversion — soft-proof before press.
  • Do not assume browser PDF color management = press color.

4. Recommended production export settings

For Fireup / commercial output

  • Rebuild or place art at 100% trim size in inches (see table).
  • Add bleed if required by Fireup (confirm; not in the dimension sheet — ask if unsure; common is 0.125"–0.25").
  • Export PDF/X-1a or PDF/X-4, CMYK, fonts outlined or embedded.
  • Raster effects / photos ≥ 150–300 ppi at final size (large boards can use 100–150 ppi if viewing distance is far — confirm with printer).
  • Keep vector type for prices/headers whenever possible.
  • Include the Red Rally Exterior frame size 196 × 48 in the job ticket if they mount into that frame.

Chrome “Save as PDF” checklist (proofs only)

  • ☑ Background graphics ON
  • ☑ Margins none / zero
  • ☑ Layout = Landscape or Portrait to match board
  • ☑ Custom paper size = Fireup inches when available
  • ☑ Scale = 100% / Default (avoid “Fit to printable area” if custom size works)
  • ☑ Filename includes location + size + RGB-proof
