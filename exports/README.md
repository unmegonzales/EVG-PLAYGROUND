# Layout shells for Canva / Adobe Illustrator

## What the "boxes" on the top right were
In the HTML boards, the four gray/colored squares next to **4 FOR $4** are **product photo placeholders** for:
1. Pepsi (16 oz)
2. Lobo Dog
3. Popcorn
4. Water

They are not random UI — they stand in for hero product photography from the Fan Favorites sample. In Illustrator/Canva, replace each PHOTO slot with the real asset (or delete the row if a board should not show the offer).

## Import tips
**Canva:** Upload SVG → set custom dimensions to match Fireup inches at your preferred px/in (e.g. 96×36 in → scale as needed) → replace PHOTO slots and type.

**Illustrator:** File → Open SVG → set artboard to real inches (Object unused; use Document Setup) → expand/recolor with brand swatches → save PDF/X for Fireup.
