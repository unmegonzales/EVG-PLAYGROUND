## In Illustrator
1. **File → Open** the SVG (or Place into your menu board).
2. Select a frame → **Object → Expand** if you want fills/strokes fully editable.
3. Swap the white-line icon group with your official vector if you have one — keep the gradient rect.
4. Scale freely; corner radius is baked into the rounded rect.

Artboard per solo file: **160 × 240 px** (portrait). Scale to print size as needed.
